# Portfolio

Static site: no build step.

## Edit
- `index.html`: replace every "Your Name", placeholder text, and email/LinkedIn link.
- `style.css`: colors are variables at the top (`--accent`, `--bg`, ...).
- Put photos in `img/` and PDFs in `papers/`. Swap each `<div class="ph">` for `<img src="img/yourfile.jpg" alt="...">`.

## Publish on GitHub Pages
1. Create a repo (e.g. `portfolio`) and upload all files in this folder.
2. Settings > Pages > Source: "Deploy from a branch" > `main` / root > Save.
3. Your site appears at `https://YOUR-USERNAME.github.io/portfolio/`.
